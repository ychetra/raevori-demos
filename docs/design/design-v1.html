Design decisions in this version (change anything):
  • Raevori's cream, ink and sage colours everywhere, so the demos feel like your work, not a template. The kitchen board is dark like real kitchen screens.
  • Menu pictures are custom drawn illustrations in one style (no stock photos, no licences to manage).
  • Khmer and English switch instantly with the EN / ខ្មែរ toggle; prices show dollars with riel underneath.
  • No status dots anywhere. A shimmering "Checking stock…" line (no bouncing dots) is the only animation besides tickets sliding in.
  • Every page has the slim black "A live demo by Raevori Studio · Build one like this →" bar.
